## Format compatibility repair

The critic and editor accepted deterministic format conversion after the failed header verification. Eight opaque runtime WebP images are encoded as optimized progressive JPEG at quality 92 with 4:4:4 chroma; three transparent sprites/hardware images become lossless PNG. All eleven preserve dimensions and composition; decoded RGBA pixels are identical for the PNG replacements. The original WebP assets and provenance-only `writing-corner.webp` remain in source. Runtime references, including the room duplicate image layers and the turntable CSS mask, SVG hardware and loading probe, move together to the replacement files. No scene behavior, content or design changes are introduced.

The total replacement transfer size is 3,757,703 bytes versus 1,009,152 bytes for the corresponding WebPs, a 2,748,551-byte compatibility cost. The 1,587,947-byte transparent turntable PNG is the largest contributor. Existing lazy loading and browser reuse of identical resource URLs remain in place. Local asset inspection checks illustration detail and Playbill lettering; this is not rendered browser QA. Postdeployment acceptance requires every replacement to return 200, the correct image/jpeg or image/png Content-Type, and bytes matching the committed file. Corporate browser restrictions remain unverified.
